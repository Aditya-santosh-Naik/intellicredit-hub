The Problem

Why traditional credit appraisal needs a revolution

Slow Manual Processes

Traditional credit evaluation requires weeks of manual document review, data collection from disparate sources, and subjective risk assessment — delaying decisions and costing operational efficiency.

Fraud & Inconsistency Risk

Without automated verification against government databases like MCA21, fraudulent CINs, PANs, and falsified financial data can slip through human review undetected.

Scattered Data Sources

Credit analysts must manually gather intelligence from news, court records (Indian Kanoon), corporate registries (Zaubacorp), and financial screeners — a time-consuming and error-prone process.

Our Solution — The 10-Stage Pipeline

End-to-end automated credit appraisal in 10 intelligent stages

1

Entity Onboarding

Captures company identity — name, CIN, PAN, sector, loan amount, and annual turnover. Real-time field-level validation ensures data integrity from the first keystroke.

2

MCA21 Verification

Cross-verifies the entity's CIN and PAN against the Ministry of Corporate Affairs registry database using a trained ML lookup model. Detects mismatches via fuzzy name matching (SequenceMatcher, 60% similarity threshold) and flags spoofed registrations.

3

Document Upload & Security

Accepts PDF, Excel, and image files with multi-layer security: MIME type validation (filetype library), SHA-256 hash deduplication, malicious payload scanning, and password-protected PDF detection. Maximum 50 MB per file.

4

AI Document Classification

Automatically classifies uploaded documents into 5 categories — ALM Statement, Shareholding Pattern, Borrowing Profile, Annual Report, and Portfolio Performance — using weighted keyword matching with spaCy NLP, achieving asymptotic confidence scoring.

5

Financial Data Extraction

Parses financial metrics (Revenue, EBITDA, PAT, Debt/Equity, DSCR, Interest Coverage, Current Ratio) from documents using regex-based text extraction with Indian currency suffix handling (Cr, L, K). When OCR fails, smart estimation derives plausible figures from turnover and loan amount using industry benchmark ratios (NBFC/Corporate standards).

6

Data Intelligence Agent

An autonomous orchestrator that collects intelligence from 3 domains using a waterfall fallback strategy:

  • News Sentiment: GNews → Google News RSS → Mock API. Headlines scored with VADER sentiment analysis.
  • Corporate Data: Zaubacorp (MCA scraper) → Screener.in → Mock API. Extracts directors, CIN, compliance status, and promoter holding.
  • Litigation Records: Indian Kanoon (court records) → Google Search → Mock API. Classifies cases as Criminal, Insolvency, Regulatory, Tax, or Civil.
7

Data Triangulation

Cross-validates financial data against intelligence findings to detect contradictions. Flags when high reported revenue contradicts negative market sentiment, when negative EBITDA compounds with active litigation, or when thin profit margins signal operational stress.

8

Explainable 5C Risk Scoring

Calculates a composite credit score (0–100) using the classic 5 Cs of Credit framework — Character (25%), Capacity (25%), Capital (20%), Collateral (15%), and Conditions (15%). Each dimension is scored independently from financial ratios and intelligence data, producing fully explainable decisions: Approve (≥75), Approve with Conditions (≥60), Review (≥45), or Reject (<45).

9

SWOT Generation

Dynamically generates a Strengths, Weaknesses, Opportunities, and Threats analysis based on actual financial metrics and intelligence signals — not static templates. Each SWOT item cites specific numbers (e.g., "DSCR of 1.85x indicates strong repayment capacity").

10

Investment Report Generation

Compiles a downloadable PDF report using ReportLab, containing the executive summary, system recommendation, financial health table, triangulation alerts, and SWOT analysis — ready for committee review.

Machine Learning Models

Trained on 500+ Indian companies across 21 sectors

Supervised

Random Forest Classifier

500-tree ensemble trained with Leave-One-Out cross-validation for sector classification from CIN/PAN structural features. Uses 13 engineered features: listing status, NIC code, state, incorporation year, company type, serial number, PAN entity type, alpha encoding, and validity flags.

scikit-learn Balanced class weights LOO-CV validated
Unsupervised

Isolation Forest

300-estimator anomaly detector with 4% contamination rate, designed to flag spoofed or structurally unusual CIN/PAN patterns that deviate from the learned distribution of legitimate Indian company registrations.

Anomaly Detection 300 estimators 4% contamination
Clustering

K-Means Clustering

Groups companies into sector-aware clusters for pattern recognition and cohort-based risk benchmarking. Cluster count derived dynamically: min(n_sectors, n_companies/6).

Pattern Recognition 15 init runs Dynamic k
Deep Learning

ANN (Dense Neural Network)

Optional secondary classifier using a 3-hidden-layer architecture (256→128→64 neurons) with BatchNormalization and Dropout. 5-fold Stratified cross-validated with early stopping. Activated when TensorFlow is available.

TensorFlow/Keras 5-Fold CV Early Stopping

System Architecture

Dual-server architecture with resilient data sourcing

Flask Server (Port 5000)

Serves the frontend UI, handles document uploads, executes financial extraction, runs the Data Intelligence Agent, and performs risk scoring. All HTML templates rendered server-side via Jinja2.

/ /cases /case/new /audit /risk /reports /about
FastAPI Server (Port 8000)

RESTful data layer with Pydantic validation, auto-generated OpenAPI docs at /docs, and CORS-enabled communication with the Flask frontend. Handles case CRUD operations and MCA verification.

/health /api/verify-mca /api/submit-case /api/cases
MongoDB

Local document store (no authentication for dev) with collections for cases, schemas, audit logs, and document metadata. Auto-generates sequential case IDs (LC-000001 format).

intellicredit.cases intellicredit.schema intellicredit.documents
Waterfall Data Sources

Each intelligence category uses a 3-tier resilient fetching strategy: primary live source → secondary scraper → mock API fallback. Guarantees the pipeline never blocks even when external APIs are unavailable.

GNews Zaubacorp Screener.in Indian Kanoon Google RSS

Key Features

What makes IntelliCredit Hub enterprise-ready

Multi-Format Document Ingestion

Supports PDF, XLSX, XLS, PNG, JPG, and TIFF with automatic text extraction using pdfplumber, Tesseract OCR, and pandas.

Smart Financial Estimation

When document parsing fails, derives company-specific financial estimates using industry benchmark ratios — so two different companies always get different numbers.

Explainable AI Decisions

Every risk score is decomposed into 5 interpretable dimensions with clear reasoning, enabling auditors to understand exactly why a decision was made.

Real-Time MCA Verification

Instant CIN/PAN cross-check against a 500+ company ML registry with fuzzy name matching to catch typos and abbreviations.

Confidence-Aware Classification

AI document classifier reports confidence scores using an asymptotic formula (capped at 99%), automatically routing low-confidence documents for manual review.

Complete Audit Trail

Every action — upload, verification, extraction, scoring — is logged with timestamps, analyst ID, and entity ID for full regulatory compliance.

Project Information

Origins, purpose, and contributors

🎯 Purpose

Developed as a comprehensive solution to a problem statement presented at the IIT Hyderabad Hackathon, addressing the challenges of automating bank credit management and financial data extraction using AI/ML. The platform aims to reduce credit appraisal turnaround from weeks to minutes while maintaining institutional-grade accuracy and auditability.

📂 Open Source

IntelliCredit Hub is open source and available on GitHub. Contributions, issues, and feature requests are welcome. The project is structured for easy extension — new data sources can be added by implementing the waterfall pattern, and new ML models can be plugged into the training pipeline.
